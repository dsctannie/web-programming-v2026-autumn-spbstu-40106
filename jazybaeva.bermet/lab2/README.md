\# Лабораторная работа 2



\## Задание



Вариант 15. Реализовать функцию, которая принимает дату и возвращает строку с описанием того, сколько времени прошло с этой даты (например, "5 минут назад", "2 часа назад", "3 дня назад" и т.д.).



\## Реализация



Решение находится в файле `solution.js` и представляет собой ES-модуль с единственным именованным экспортом `timeAgo`.



Функция `timeAgo(date)`:



\- принимает дату в любом формате, который понимает `new Date()`;

\- вычисляет разницу между текущим моментом и переданной датой в секундах;

\- обрабатывает граничные случаи: если дата в будущем — возвращает "в будущем", если прошло меньше 5 секунд — "только что";

\- подбирает подходящую единицу измерения (секунды, минуты, часы, дни, месяцы, годы), проходя по массиву единиц от меньшей к большей;

\- использует вспомогательную функцию `plural` для правильного русского склонения слов ("1 минута", "2 минуты", "5 минут"), включая особый случай для чисел 11–14.



Функция возвращает строку и не изменяет переданные данные.



\## Запуск



Функцию можно импортировать в любом JavaScript-окружении, поддерживающем ES-модули:



```javascript

import { timeAgo } from './solution.js';



console.log(timeAgo(new Date(Date.now() - 5000)));        // "5 секунд назад"

console.log(timeAgo(new Date(Date.now() - 300000)));      // "5 минут назад"

console.log(timeAgo(new Date(Date.now() - 7200000)));     // "2 часа назад"

console.log(timeAgo(new Date(Date.now() - 259200000)));   // "3 дня назад"
